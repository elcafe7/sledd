# sledd

## PowerPoint energy, terminal ergonomics

Write slides in **Markdown** and present them without leaving the command line.

<!-- notes
This bundled deck is what LAUNCHER opens.
-->

---

# Navigation

- `→` — next slide
- `←` — previous slide
- `Esc` — leave slide mode

---

# Make your own

```sh
sledd --init my-talk.md
sledd my-talk.md
```

See `README.md` for the compact format contract written for humans and AI agents.
